# FitLife Coach Static Site

This project is now a plain static landing page built with:

- HTML
- CSS
- Bootstrap 5 (CDN)
- Vanilla JavaScript

No React, TypeScript, Tailwind, or Vite build step is required.

## Run Locally

Option 1: Open `index.html` directly in your browser.

Option 2: Serve locally with Node.js:

1. Run `npm run start`
2. Open the localhost URL shown in the terminal

## Deploy to GitHub Pages

1. Push this repository to GitHub
2. Go to repository Settings -> Pages
3. Set Source to "Deploy from a branch"
4. Choose your main branch and root folder (`/`)
5. Save and wait for deployment

Your site will deploy as a static page.
